# FitPulse Gym Management System (EAD 02 Coursework)

This repository contains the microservices for the Gym Management System coursework:

## Modules

- **[Owner](./Owner)**: Gym Admin / Owner module managing Equipment inventory, customer Invoices, and Owner Dashboard metrics.
- **[Trainer](./Trainer)**: Trainer module managing Personal Trainers, Workout Plans, Supplement catalog, and Supplement Orders.
